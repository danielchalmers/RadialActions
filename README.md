# 🪄 Radial Actions

[![Release](https://img.shields.io/github/release/danielchalmers/RadialActions?include_prereleases)](https://github.com/danielchalmers/RadialActions/releases)
[![License](https://img.shields.io/github/license/danielchalmers/RadialActions)](LICENSE)

Radial Actions is a free Windows app that opens with a global hotkey. It gives you a fast pie menu for launching apps, opening files and folders, controlling media, changing volume, and running custom keyboard shortcuts.

## Installation

### Option 1: Download Installer (Recommended)

1. Download the latest `.msi` release from the [Releases page](https://github.com/danielchalmers/RadialActions/releases).
   - `x64` for most Intel and AMD Windows PCs.
   - `arm64` for Windows on ARM devices.
2. Run the installer.
3. Wait for it to open.

### Option 2: Download Portable Version

1. Download the latest `.zip` release from the [Releases page](https://github.com/danielchalmers/RadialActions/releases).
2. Extract to your preferred location.
3. Run `RadialActions.exe`.

### Option 3: Build from Source

1. Clone the repository.
2. Open `RadialActions.sln` in Visual Studio 2022 or later.
3. Build and run.
